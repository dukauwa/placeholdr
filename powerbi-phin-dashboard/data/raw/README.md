# Drop zone for PHIN datasheets

Save the downloaded Excel datasheets here (keep PHIN's original file names):

- Hospital Reported Adverse Events — <https://www.phin.org.uk/data/hospital-reported-adverse-events-datasheets>
- Patient Feedback — <https://www.phin.org.uk/data/patient-feedback-datasheets>
- Never Events — <https://www.phin.org.uk/data/never-events-datasheets>
- Infections — <https://www.phin.org.uk/data/infections-datasheets>

The prep pipeline matches files to datasets by keywords in the file name:
`adverse`, `feedback` or `satisfaction`, `never`, `infection`.

Files in this folder are git-ignored.
